## Purpose

Показывать ученику прогресс и предстоящие повторы и отправлять ненавязчивые, дедуплицированные напоминания с учётом его часового пояса и отписки.

## ADDED Requirements

### Requirement: Learning dashboard
Дашборд MUST показывать серию (день засчитан только завершённым занятием), одну заморозку в неделю, минуты недели против цели, слова, освоение по уровням и ближайшие повторы. Основание: FR-COA-1.

#### Scenario: Repeat lesson completion
- **WHEN** одно занятие завершено повторным запросом в тот же локальный день
- **THEN** день и минуты не удваиваются, незавершённое занятие само по себе серию не увеличивает.

### Requirement: Timezone-aware reminders
Worker MUST планировать ежедневное письмо в выбранное время только без занятия сегодня и не чаще одного в день, возвратные письма на 3/7 дней, окончание доступа за 7 дней/1 день/после. Планировщик проверяет каждые 15 минут. Основание: FR-COA-3, ТЗ 8.4.

#### Scenario: Concurrent schedulers
- **WHEN** два запуска scheduler выбирают одного ученика и локальный день
- **THEN** создаётся одно логическое уведомление с уникальным dedupe key.

#### Scenario: Lesson completed before delivery
- **WHEN** после планирования ежедневного письма ученик завершил занятие до отправки
- **THEN** неактуальное ежедневное напоминание не отправляется.

### Requirement: Unsubscribe and safe links
Каждое коучинговое письмо MUST иметь подписанную отписку, профиль — общий переключатель; недействительная подпись не меняет настройки. Отключение напоминаний MUST не отменять необходимые письма безопасности/платежей. Основание: FR-COA-3, ТЗ 13.9.

#### Scenario: Unsubscribe before queued send
- **WHEN** ученик отписался до отправки уже запланированного напоминания
- **THEN** отправка подавляется, повтор ссылки безопасен.

### Requirement: First-release coaching boundary
MVP MUST включать FR-COA-1/3; недельные AI-отчёты FR-COA-2 и специальное короткое занятие возвращения FR-COA-4 остаются этапом 3 согласно разделу 11. Обычные возвратные письма этапа 1 сохраняются.

#### Scenario: MVP feature set
- **WHEN** проверяется готовность первого релиза
- **THEN** отсутствие недельного AI-отчёта не подменяет требование работающих ежедневных и возвратных писем.
