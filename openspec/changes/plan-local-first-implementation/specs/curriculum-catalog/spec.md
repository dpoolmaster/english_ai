## Purpose

Представить учебную программу графом навыков и проверенным словарём, чтобы планировщик учитывал зависимости, уровень и цель ученика.

## ADDED Requirements

### Requirement: Skill graph
Навык MUST иметь стабильный код, название, вид grammar/vocab_set/pronunciation/function, CEFR, русское «умею», объяснение до 250 слов с 2–4 EN/RU примерами и порядок. Зависимости MUST быть ацикличными. Основание: FR-CUR-1.

#### Scenario: Cycle introduced
- **WHEN** сохранение зависимости создаёт прямой или косвенный цикл, в том числе при конкурентных изменениях
- **THEN** сохранение отклоняется, опубликованный граф остаётся ацикличным.

### Requirement: Vocabulary contexts and goals
Слово MUST иметь уровень, перевод и 3–5 проверенных примеров; цель ученика MUST определять веса навыков. Основание: FR-CUR-2/4, FR-SRS-5.

#### Scenario: Different learning goals
- **WHEN** одинаково подготовленные ученики имеют разные цели
- **THEN** planner получает соответствующие goal weights без изменения prerequisites и опубликованности.

### Requirement: Import and content-only expansion
Каталог MUST поддерживать проверяемый импорт навыков, зависимостей, слов и примеров; ошибка импорта не должна оставлять повреждённый граф. Добавление B1/B2 MUST не требовать изменения учебного кода. Основание: FR-CUR-2/3, ТЗ 8.1.

#### Scenario: Invalid import
- **WHEN** импорт содержит неизвестную зависимость, повтор кода или цикл
- **THEN** показываются ошибки и не фиксируется частично повреждённая программа.

#### Scenario: Future content level
- **WHEN** подготовлен валидный набор B1/B2 по действующим схемам
- **THEN** его можно добавить обычным контентным процессом без новой версии алгоритма занятий.
