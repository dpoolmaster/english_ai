## Purpose

Генерировать учебный контент заранее с проверками, человеческим ревью, воспроизводимыми версиями промптов и измеримой стоимостью подготовки.

## ADDED Requirements

### Requirement: Traceable batch generation
Администратор MUST запускать генерацию по skill/type/count/prompt version/model и видеть прогресс/стоимость. Результат MUST сохранять происхождение и идти через schema/автопроверки/ревью, а не сразу ученику. Основание: ТЗ 8.1, FR-ADM-1.

#### Scenario: Worker retries batch
- **WHEN** генерационная задача повторяется после частичного успеха
- **THEN** готовые элементы не дублируются, объём выполненной работы и стоимость остаются прослеживаемыми.

### Requirement: Automatic quality gates
Перед публикацией MUST проверяться решение второй моделью без ключа, единственность правильного варианта, не более 5% лексики выше уровня, длина, content_hash/триграммы >0,8, стоп-лист тем и минимум два варианта translate_to_en. Расхождения MUST отклоняться либо явно направляться на ручное ревью. Основание: ТЗ 8.1.

#### Scenario: Solver disagreement
- **WHEN** вторая модель возвращает не совпадающее с ключом решение
- **THEN** элемент отмечается как спорный и не проходит незаметно в published.

#### Scenario: Duplicate or unsuitable text
- **WHEN** найдены дубликат, избыток сложной лексики или запрещённая тема
- **THEN** причина видна reviewer, автоматическое утверждение отсутствует.

### Requirement: Immutable prompt versions and eval
Промпты MUST изменяться только новой версией, иметь одну активную версию на имя и откат переключением. Для tutor/error_analysis/content_gen и будущего writing MUST существовать эталонные eval; регресс MUST блокировать активацию до ручного решения. Основание: ТЗ 8.3.

#### Scenario: Version activation race
- **WHEN** два администратора одновременно активируют версии одного имени
- **THEN** активной остаётся ровно одна, изменение аудируется и известно, какая версия применена к каждой задаче.

#### Scenario: Regression detected
- **WHEN** новая модель или промпт ухудшает эталонные результаты
- **THEN** версия не активируется автоматически, результаты сравнения доступны для решения.
