## Purpose

Определить стартовые настройки и уровень ученика адаптивной диагностикой, сохраняя воспроизводимую оценку и историю карты знаний.

## ADDED Requirements

### Requirement: Initial learning preferences
После подтверждения email система MUST предложить цель work/relocation/travel/exam/hobby, 5/10/15/20 минут, редактируемую timezone, время напоминания и выбор диагностики либо старта A1. Основание: FR-ONB-1.

#### Scenario: Start from zero
- **WHEN** ученик выбирает начать с нуля
- **THEN** задаётся A1 и онбординг завершается без фиктивного прохождения placement.

### Requirement: Adaptive diagnostic algorithm
Диагностика MUST использовать отдельный банк минимум 120 вопросов, по 30 на A1–B2, типов grammar/vocab/reading; P=c+(1−c)σ(θ−b), c=1/k, θ start −0,5, MAP prior N(0;1,5²). Следующий вопрос ближайший по b с балансом типов не ниже 20%; SE=1/sqrt(sum p(1−p)); остановка после минимум 12 при SE<0,4 либо после 25. «Не знаю» MUST считаться неверным без угадывания. Основание: FR-ONB-2.

#### Scenario: Stopping conditions
- **WHEN** пройдены 12 вопросов без достижения SE либо достигнут 25-й
- **THEN** в первом случае тест продолжается, во втором завершается независимо от SE; вопросы не повторяются.

#### Scenario: Simulation acceptance
- **WHEN** выполнена фиксированная симуляция 1000 учеников с известным θ
- **THEN** средняя абсолютная ошибка не превышает половины уровня CEFR и каждый тест укладывается в 25 вопросов; несоответствие блокирует приёмку, а не вызывает скрытую замену формул.

### Requirement: Results and state seeding
Пороги θ MUST конфигурироваться с defaults −1,5/−0,3/+0,9; результат показывает уровень, сильные/слабые разделы и цель. Освоение ниже/на/выше уровня MUST засеваться 0,85/0,4/0,05 по конфигурации. Основание: FR-ONB-2.

#### Scenario: Completion replay
- **WHEN** завершение диагностической сессии повторено
- **THEN** результат и засев применяются один раз без повторного стирания учебного состояния.

### Requirement: Retest and calibration
Повтор MUST быть доступен раз в 30 дней без стирания истории. Начальные b: −2/−1/+0,3/+1,5; эксперт может их править, worker перекалибрует только items с минимум 200 ответами. Основание: FR-ONB-2.

#### Scenario: Insufficient calibration data
- **WHEN** weekly recalibration видит вопрос со 199 ответами
- **THEN** его b не пересчитывается, ответы и прежняя сложность сохраняются.
