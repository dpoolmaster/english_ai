## Purpose

Ограничить платные внешние операции по тарифу без гонок между запросами, двойного списания и расхода квоты при неуспешном результате.

## ADDED Requirements

### Requirement: Configurable quota periods
Система MUST поддерживать тарифные defaults tutor messages/day trial 30/paid 200, voice minutes/month 10/300, writing/day 3/10 и предупреждение 80%; голос/письмо активируются в своих этапах. Основание: FR-BIL-6.

#### Scenario: Near limit
- **WHEN** успешное потребление достигает 80% текущего лимита
- **THEN** ученик видит предупреждение и корректный остаток без преждевременного полного запрета.

### Requirement: Admission before external call
Квота MUST проверяться до внешнего вызова; параллельные операции MUST не обходить остаток. Учёт MUST оставаться согласованным между web/worker и несколькими вкладками. Основание: FR-BIL-6, FR-TUT-4.

#### Scenario: Last remaining unit
- **WHEN** два запроса конкурентно запрашивают последнюю единицу
- **THEN** к платному действию допускается не более одного; отказанный запрос не вызывает провайдера.

### Requirement: Successful exactly-once consumption
Расход MUST фиксироваться атомарным UPSERT после успешного результата и идемпотентно по операции. Неуспешный fallback MUST не списывать квоту; попытки провайдера всё равно учитываются как стоимость. Основание: FR-BIL-6, FR-TUT-7.

#### Scenario: Failure and retry
- **WHEN** primary и fallback завершились ошибкой
- **THEN** подтверждённый расход не увеличивается, временно занятый остаток освобождается, стоимость попыток наблюдаема.

#### Scenario: Result commit replay
- **WHEN** фиксация успешной операции повторяется
- **THEN** результат доступен, счётчик увеличен ровно один раз.

### Requirement: Crash and period recovery
Незавершённые операции MUST восстанавливаться после падения без вечной блокировки остатка; изменение периода MUST не переносить старый расход в новый или скрыто списывать результат дважды. Основание: ТЗ 3.1, FR-BIL-6.

#### Scenario: Crash after admission
- **WHEN** процесс упал с временно занятым лимитом
- **THEN** восстановление разрешает состояние операции по её результату и не освобождает вслепую ещё выполняющийся подтверждённый вызов.
