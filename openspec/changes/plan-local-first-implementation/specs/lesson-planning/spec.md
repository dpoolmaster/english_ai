## Purpose

Собирать детерминированные занятия из повторений, слабых мест и новых навыков с учётом зависимостей, цели, лимитов и опубликованного контента.

## ADDED Requirements

### Requirement: Deterministic candidates
Planner MUST выбирать due <= now по просрочке, слабые навыки/топ-3 ошибок за 14 дней и новое с prerequisites >= 0,7 по goal weight/порядку. При одинаковых данных/времени/seed результат MUST совпадать. Основание: ТЗ 4.5.

#### Scenario: Identical build
- **WHEN** сборка повторена на том же снимке с тем же временем и seed
- **THEN** состав и порядок совпадают независимо от порядка обхода коллекций.

### Requirement: Composition and limits
Доли MUST настраиваться с defaults 50/25/25 и перераспределением пустой категории соседней. Размер — targetMinutes × 1,3 с границами 6–26; новых навыков не более 1/занятие и 2/день по конфигурации. Основание: ТЗ 4.5.

#### Scenario: Parallel new lessons
- **WHEN** занятия одновременно создаются у дневного лимита
- **THEN** суммарный выбор новых навыков не обходит лимит.

#### Scenario: Empty category
- **WHEN** нет доступного нового навыка
- **THEN** доля перераспределяется без нарушения prerequisites.

### Requirement: Ordering and adaptation
Новый навык MUST начинаться с объяснения и трёх лёгких заданий; остальные перемешиваются, не более трёх подряд одного типа. Две ошибки подряд по навыку MUST добавлять одно облегчённое задание и правило. Основание: ТЗ 4.5.

#### Scenario: Repeated adaptation trigger
- **WHEN** POST второй ошибки повторяется
- **THEN** очередь адаптируется один раз для исходного события.

### Requirement: Content gaps
Навык с недостатком опубликованных упражнений MUST пропускаться с planner.content_gap, доступным в админке. Основание: ТЗ 4.5.

#### Scenario: No published candidates
- **WHEN** подходящего контента нет во всех категориях
- **THEN** возвращается понятный результат нехватки, draft не подставляется в занятие.
